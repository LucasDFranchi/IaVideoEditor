# Media Assets

This directory contains media files used in the IAVideoEditor project.

## Structure

- **videos/** - Base video files for editing and processing
- **audio/** - MP3 and audio files (background music, voiceovers, sound effects)

## Notes

- Add your base video and MP3 files to their respective folders
- These files are typically ignored by git (see .gitignore)
- Video formats supported: MP4, AVI, MOV, etc.
- Audio formats: MP3, WAV, FLAC, etc.
